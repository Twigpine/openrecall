# OpenRecall brand assets

The mark is an open memory loop with two lines of stored context. Its open
corner suggests returning to work with the context already there.

- [Mark](./openrecall-mark.svg): square icon for avatars and compact placements.
- [Wordmark for light backgrounds](./openrecall-logo.svg): transparent
  horizontal lockup in pine ink.
- [Wordmark for dark backgrounds](./openrecall-logo-dark.svg): transparent
  horizontal lockup in paper ink.
- [README banner](./openrecall-banner.svg): fixed dark surface for consistent
  contrast on GitHub and npm.
- [Mobile banner](./openrecall-banner-mobile.svg): a simpler composition for
  narrow screens, selected through the README's `picture` element.

| Color | Hex | Use |
|---|---|---|
| Pine | `#102C29` | primary ink and dark surfaces |
| Mint | `#AEF4CE` | mark, emphasis, and active connections |
| Paper | `#EEF8F2` | light text |
| Sage | `#89AEA0` | supporting text on dark surfaces |

Keep the mark square, preserve its proportions, and leave clear space around
it. SVG sources are self-contained and editable, with no remote fonts, scripts,
or linked images. These assets are covered by the repository's MIT license.
